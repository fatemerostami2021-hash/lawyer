# پورتال موکلان + پنل مدیریت وکیل (نسخه نمونه)

## نصب (یک‌بار)
۱. این زیپ را در پوشه‌ی اصلی پروژه (همان‌جا که `package.json` و `vite.config.ts` هست) Extract کنید و اگر پرسید Replace، بله.
۲. در Git Bash:
```
cd /e/lawyer
node apply-portal.mjs
bash start-demo.sh
```
بار اول چند دقیقه طول می‌کشد (نصب پکیج‌ها). بعد از آن فقط `bash start-demo.sh`.

## آدرس‌ها
- سایت: http://localhost:3000
- **پنل وکیل:** http://localhost:3000/admin — کاربر `lawyer` رمز `Demo@1234` (منشی: `assistant` / `Demo@1234`)
- **پورتال موکل:** http://localhost:3000/portal — شماره‌های نمونه `09120000001` تا `09120000020` (کد روی صفحه نمایش داده می‌شود)

## اتصال تلگرام (تست)
۱. اجرا کنید. در ترمینال باید ببینید: `bot @Fitmindsetbot ready`
۲. در تلگرام ربات را باز کنید و **/start** بفرستید (همین الان، قبل از هر کس دیگر؛ اولین نفر مالک ربات می‌شود).
۳. در پورتال موکل (مثلاً با ۰۹۱۲۰۰۰۰۰۰۰۲) نوبت بگیرید → پیام با دکمه‌های ✅ تأیید / ❌ رد / 🕐 پیشنهاد زمان دیگر برای شما می‌آید.
۴. دستورهای ربات: `/today` برنامه امروز، `/pending` نوبت‌های در انتظار، `/stats` آمار.

**مهم:** تلگرام در ایران فیلتر است؛ برای اتصال ربات، VPN سیستم‌عامل (نه فقط مرورگر) باید روشن باشد. اگر خاموش بود، سرور هر ۱۵ ثانیه دوباره تلاش می‌کند.

## سناریوی نمایش برای وکیل (۵ دقیقه)
۱. داشبورد: آمار، نمودار درآمد، برنامه امروز.
۲. در گوشی/پورتال موکل نوبت بگیرید ← پیام تلگرام ← تأیید با یک دکمه ← موکل در پورتال می‌بیند.
۳. موکل‌ها ← یک موکل ← پرونده، مدارک، مالی. ۴. تقویم و مهلت‌ها. ۵. گزارش ← Excel/PDF. ۶. تنظیمات ← خاموش/روشن‌کردن نوبت حضوری/آنلاین/تلفنی.
قبل از ارائه: تنظیمات ← «بازنشانی داده‌های نمونه».

## نکته‌ها
- داده‌ها در `portal-api/data/db.json` و فایل‌ها در `portal-api/uploads` ذخیره می‌شود (برای نمونه کافی است؛ برای نسخه واقعی به MongoDB Atlas منتقل می‌شود).
- همه موکلان نمونه **خیالی** هستند. شماره‌ها واقعی نیستند.
- واتساپ: دکمه «واتساپ» پیام آماده را در واتساپ باز می‌کند. اتصال خودکار پس از دریافت API بیزنس.
- **توکن ربات** را در گیت قرار ندهید (`.env` در `.gitignore` است). بعد از دمو در BotFather دستور `/revoke` بزنید.
